# Landing Pages Mockups

This project contains a simple gallery of landing page mockups displayed as card components.

## Structure

- `index.html`: Main page that renders the mockup cards.
- `assets/styles.css`: Project styles for cards, scrollable image areas, and UI details.
- `assets/script.js`: JavaScript for any page interactions.
- `assets/*.png`: Mockup images used by the cards.

## Notes

- The hover zoom effect on cards has been removed to keep the layout stable while browsing.
- Images are shown inside scrollable containers to support tall mockups.

## Usage

Open `index.html` in a browser to view the project.
